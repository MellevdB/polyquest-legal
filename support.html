Getting an API key

An API key is not the same as a ChatGPT, Claude or Gemini subscription. Keys are billed separately by the provider.

  • Claude: platform.claude.com → Settings → Billing (add a small credit) → API keys → Create key.
  • OpenAI: platform.openai.com → Billing → API keys.
  • Gemini: aistudio.google.com → Get API key.

Copy the key right away; most providers show it only once.

Common problems

  • "No credit" or "billing" error: add credit to your API account.
  • "Key rejected": check that you copied the whole key and chose the right provider.
